# بيت المسلم — النسخة الثابتة الجاهزة للنقل

هذه حزمة الموقع الحالي كما هو، مع ملفات التصميم والوظائف والتلاوات الصوتية المضمّنة. ارفع محتويات المجلد إلى جذر موقعك في الاستضافة، مع الإبقاء على مجلد `audio` في مكانه.

## محتويات الحزمة

- `index.html` — صفحة الموقع.
- `style.css` — التنسيق والتصميم.
- `script.js` — وظائف الموقع وبياناته.
- `audio/tilawa1.mp3` — سورة القصص، الشيخ عبد الباسط عبد الصمد، مسجد الإمام الشافعي.
- `audio/tilawa2.mp3` — سورة المائدة، الشيخ السيد سعيد.
- `audio/tilawa3.mp3` — سور ق والرحمن، الشيخ محمد صديق المنشاوي.
- `audio/tilawa4.mp3` — سورة القصص، الشيخ مصطفى إسماعيل.
- `audio/tilawa5.mp3` — سور مريم والتكوير والقدر، الشيخ عبد الباسط عبد الصمد.

التسجيلات المضمّنة ملفات MP3 أحادية القناة ومهيّأة للويب لتقليل حجم التنزيل. لا تغيّر أسماء الملفات أو مسارات مجلد `audio`.

## التشغيل محلياً

لا يحتاج الموقع إلى تثبيت Node.js أو تشغيل خادم خاص عند رفعه إلى استضافة ملفات ثابتة. لمعاينته محلياً، فك الضغط وافتح الطرفية داخل مجلد الموقع، ثم شغّل:

```bash
python3 -m http.server 8000
```

افتح `http://localhost:8000`. تشغيله من خلال خادم محلي يساعد ميزات المتصفح التي تتصل بخدمات الإنترنت الخارجية.

## النشر على استضافة خارجية

1. فك ضغط `baytalmuslim-static.zip`.
2. ارفع **محتويات** المجلد إلى مجلد الموقع الرئيسي في الاستضافة (غالباً `public_html` أو `www`).
3. تأكد أن `index.html` في جذر الموقع، وأن الملفات الأخرى بجواره، وأن ملفات الصوت داخل `audio/`.
4. افتح رابط الموقع. إذا ظهرت نسخة مخزنة قديمة، حدّث الصفحة مع مسح الذاكرة المؤقتة.

هذه بنية موقع ثابت؛ يمكن استضافتها على خدمة ملفات ثابتة مجانية مثل GitHub Pages أو Cloudflare Pages أو Netlify، أو على الاستضافة المشتركة الحالية. شروط الاستخدام والحصص والتوفر تختلف حسب المزود، لذا راجع حدود خطته المجانية.

## التقنيات والمتطلبات

- HTML وCSS وJavaScript عادي — لا يوجد إطار عمل للواجهة ولا حاجة إلى بناء أو تثبيت حزم.
- لا يحتاج الموقع إلى Backend خاص أو قاعدة بيانات أو متغيرات بيئة أو مفاتيح API سرية.
- مشروع Express الموجود في نسخة التطوير يُستخدم لتشغيل المعاينة، ويقدّم فحص صحة بسيطاً؛ صفحة الموقع لا تعتمد على API الخادم ولا تحتاجه في الاستضافة الخارجية.
- يحفظ الموقع إعدادات السبحة والقارئ والوضع الليلي في `localStorage` على جهاز المستخدم.

## اتصالات الإنترنت الخارجية

تعمل الواجهة محلياً، لكن بعض الميزات تحتاج اتصالاً بالإنترنت وخدمات أطراف خارجية:

- **الخطوط:** Scheherazade New وAmiri من Google Fonts. إذا تعذر الاتصال بها، يستخدم المتصفح خطوطاً بديلة.
- **نص القرآن في شاشة القراءة:** يستخدم الموقع واجهات عامة من AlQuran Cloud، ثم jsDelivr، ثم Quran.com كبدائل. لا تحتاج إلى مفتاح، لكن توفرها خاضع لمزوديها.
- **تلاوات صفحة القرآن:** روابط الصوت تُحمّل من مواقع خارجية مذكورة في `script.js`؛ يلزم الإنترنت وقد تختلف إتاحتها بمرور الوقت.
- **المساعد الذكي:** يرسل الطلبات مباشرة إلى واجهة Pollinations العامة من المتصفح. لا يحتاج مفتاحاً سرياً في إعداد الموقع، لكن عمله يعتمد على توفر الخدمة وسياساتها.

لا توجد صور أو ملفات خطوط محلية مطلوبة في هذه النسخة؛ الأيقونة الصغيرة مضمنة داخل `index.html`، والتلاوات النادرة الخمس محلية داخل `audio/`.

## ملاحظات على البيانات

- مواقيت الصلاة ثابتة ومدخلة يدوياً في `script.js` كما في الموقع الحالي؛ ليست محسوبة حسب موقع المستخدم.
- ميزات تعتمد على الإنترنت لا تعمل دون اتصال. أما ملفات التلاوات النادرة وإعدادات المستخدم فتُحمّل محلياً من الحزمة أو من تخزين المتصفح.
- لم يُحذف أو يُعدّل أي قسم أو محتوى من الموقع لأجل هذه الحزمة.
